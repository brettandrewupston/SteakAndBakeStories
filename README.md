## Steak and Bake Stories

**Steak and Bake Stories** is a browser-based AI interactive fiction and story generator built around replayable adventures, persistent world state, character interaction, and player choice.

Rather than relying on an AI model to remember everything on its own, the project uses structured game state to track important information such as characters, relationships, locations, progression, and story-specific systems. The AI handles narration and dialogue while the surrounding engine maintains continuity.

### Features

* AI-driven interactive stories and roleplay
* Multiple playable adventures and settings
* Character creation with optional random generation
* Persistent character and world state
* Dynamic NPC dialogue and relationships
* Story-specific progression systems
* Mobile and desktop browser support
* Save/import/export functionality
* AI-generated visual assets and themed interfaces
* Replayable scenarios with different outcomes

The project is designed as a lightweight **AI RPG / interactive fiction platform** where each adventure can use its own rules, systems, characters, and presentation while sharing the same underlying story engine
